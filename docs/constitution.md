# Constitución del proyecto

1. La IA recoge y organiza; el empleado valida precio, compatibilidad, ubicación y entrega.
2. No se inventan stock, referencias, precios, certificados ni trámites.
3. Las claves y datos personales nunca se exponen en el cliente.
4. Cada solicitud tiene estado, responsable y próxima acción.
5. El español inicial es `es-ES` y la comunicación debe ser clara y breve.
6. Toda funcionalidad nueva tendrá criterio de aceptación y prueba.
